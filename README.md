# Resume / Engineering Portfolio

Modern, static-deployable Next.js portfolio with MDX case studies and structured
content in `/content`.

## Local development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Content structure

- `content/profile.json` -- primary profile card and contact info
- `content/experience.json` -- timeline entries
- `content/projects/*.mdx` -- project case studies (frontmatter + MDX body)
- `content/legacy/` -- scraped legacy site outputs (generated by script)
- `public/images/` -- all images and diagrams

## Add a new project

1. Create a new file in `content/projects/your-project-slug.mdx`.
2. Use the same frontmatter structure as existing projects:

```mdx
---
slug: your-project-slug
title: "Project Title"
dates: "Jan 2026 - May 2026"
context: "Industry"
role: "Your Role"
summary: "One sentence summary."
tags:
  - Controls
  - Embedded
reminders:
  - "Interview talking point."
technologies:
  - PLC
links:
  - label: "Repository"
    url: "https://example.com"
hero:
  image: "/images/placeholders/hero.svg"
  alt: "Hero image placeholder"
sections:
  - heading: "System Architecture"
    body: >
      Short paragraph describing the system.
    figures:
      - image: "/images/placeholders/figure.svg"
        alt: "Figure coming soon"
        caption: "Architecture diagram placeholder."
    codeBlocks:
      - language: "python"
        description: "Key pipeline routine."
        placeholder: true
---
Optional MDX body for extra narrative.
```

3. Replace placeholder images with real diagrams by dropping files into
   `public/images/` and updating the `image` paths in frontmatter.

## Scrape the legacy site

```bash
npm run scrape:legacy
```

The script outputs normalized MDX + JSON into `content/legacy/` and is safe to
rerun.

## Deploy on Vercel (free tier)

1. Push the repository to GitHub.
2. In Vercel, click **New Project** and import the repo.
3. Framework preset: **Next.js** (no env vars required).
4. Build command: `npm run build`
5. Output: default Next.js output.

After deployment, update `src/lib/site.ts` with your production URL so OpenGraph
metadata renders correctly.
